Complex systems composed of many interacting, random parts are ubiquitous in science and engineering. From the movement of molecules in a gas to the firing of neurons in the brain, tracking each individual component is often a hopeless task. The goal of theoretical modeling is to find a simpler, macroscopic law that governs the system's average behavior. This "mean-field" approach shifts our focus from the chaotic micro-scale to the predictable macro-scale.

This post tells the story of one such journey. We begin with a seemingly simple manufacturing pipeline where machines have random capacities. This simple setup quickly reveals complex, unpredictable behavior. We will show how, by adopting a continuous perspective and introducing a single, powerful physical assumption, this entire stochastic process can be described by a solvable Partial Differential Equation (PDE).

Our derivation will take us from a discrete, random process to a continuous, deterministic one, culminating in a closed-form solution that predicts how material accumulates in the pipeline over time. This journey is a microcosm of how theoretical physics and applied mathematics can be used to find order in chaos.

---

### The Setup: A Stochastic Pipeline

Let's begin by defining the system precisely.

**The Stochastic Process.** We consider a pipeline of machines, indexed $k=0, 1, 2, \ldots$. On each day, which we treat as a discrete time step $t$, the system operates as follows:

- **Input:** The first machine ($k=0$) receives a deterministic input of **1 unit** of material.
- **Capacity:** Each machine $k$ has a random capacity for the day, $X_k(t)$, drawn independently from a uniform distribution, $X_k(t) \sim \text{Unif}[0,1]$.
- **Output:** Machine $k$ processes an amount of material equal to the **minimum** of its capacity and the total material available to it (its own storage plus any new input). This becomes its output, $O_k(t)$.
- **Storage:** Material that is available but not processed remains in storage for the next day, $S_k(t)$.

**Random Variables.** The system is governed by the evolution of two key random variables: the **storage** $S_k(t)$ and the **output** $O_k(t)$. Their dynamics are given by:

\begin{align}
O_k(t) &= \min(X_k(t), S_k(t-1) + O_{k-1}(t)) \cr
S_k(t) &= S_k(t-1) + O_{k-1}(t) - O_k(t)
\end{align}

where $O_{-1}(t) \equiv 1$ represents the input to the first machine.

Our goal is to find analytical expressions for the **expected values** of these quantities over many independent runs:
- Expected Storage: $s_k(t) = E[S_k(t)]$
- Expected Output: $o_k(t) = E[O_k(t)]$

---

### The Mean-Field Approach

The first step in taming this complexity is to move from a discrete model to a continuous one, treating the machine index $k$ and time $t$ as continuous variables.

**The PDE Approximation.** The discrete conservation law, $s_k(t) - s_k(t-1) = o_{k-1}(t) - o_k(t)$, can be approximated by a continuous Partial Differential Equation (PDE). The change in time becomes a time derivative, $\frac{\partial s}{\partial t}$, while the change across machines becomes a spatial derivative, $-\frac{\partial o}{\partial k}$. This gives the fundamental conservation law:

$$\frac{\partial s(k,t)}{\partial t} = -\frac{\partial o(k,t)}{\partial k}$$

**The Key Physical Assumption.** To solve this, we need a "closure relation" that connects the expected output $o(k,t)$ to the expected storage $s(k,t)$. This is where we introduce our core physical assumption, motivated by similar phenomena in queueing theory:

- **The storage $S(k,t)$ is a random variable that follows an exponential distribution.**

The mean of this distribution is the expected storage $s(k,t)$. For an exponential distribution with rate $\lambda$, the mean is $1/\lambda$. Thus, we have the crucial link: $s(k,t) = 1/\lambda(k,t)$.

---

### Deriving the Output Law: The System's Physics

With our key assumption in place, we can derive the relationship between output and storage. This refined model accurately reflects the simulation by including the daily input from the previous machine, which we approximate as a random variable $Y \sim \text{Unif}[0,1]$.

The expected output is a function of the machine's own stochastic storage $S_k$ and the stochastic input $Y$:

$$o(k,t) = E[\min(X_k, S_k + Y)]$$

where $X_k \sim \text{Unif}[0,1]$, $S_k \sim \text{Exp}(\lambda_k)$, and $Y \sim \text{Unif}[0,1]$.

**The Asymptotic Approximation.** The exact integral for this expectation is intractable. We therefore find its behavior for large storage ($s \to \infty$, which means $\lambda \to 0$). This involves first finding the expectation for a fixed storage value $z$, which gives the function $g(z) = \frac{(z-1)^3}{6} + \frac{1}{2}$, and then averaging this over the exponential distribution of storage. The asymptotic result is:

$$o(s) \approx \frac{1}{2} - \frac{1}{24s}$$

This provides the accurate, tractable relationship we need. For a detailed derivation of this result, please see the appendix of this post.

**The Tractable PDE.** We now substitute this physically accurate output law into our conservation PDE:

\begin{align}
\frac{\partial s}{\partial t} &= -\frac{\partial}{\partial k}\left(\frac{1}{2} - \frac{1}{24s}\right) \cr
&= -\frac{1}{24s^2}\frac{\partial s}{\partial k}
\end{align}

This is the final, solvable PDE that governs the system's long-term dynamics.

---

### The Final PDE and its Solution

We now present the complete, first-principles solution to the PDE $\frac{\partial s}{\partial t} = -\frac{1}{24s^2}\frac{\partial s}{\partial k}$ with the initial condition $s_k(0)=0$.

**Step 1: The Ansatz.** We assume a solution of the form $s(k,t) = c(k)\sqrt{t}$, which separates the variables. Substituting this into the PDE yields:

\begin{align}
\frac{c(k)}{2\sqrt{t}} &= -\frac{1}{24(c(k)\sqrt{t})^2} \left(\frac{d c(k)}{dk}\sqrt{t}\right) \cr
&= -\frac{c'(k)}{24c(k)^2\sqrt{t}}
\end{align}

**Step 2: Solving for the Coefficient Function $c(k)$.** The time dependence cancels, leaving a separable ODE for $c(k)$:

\begin{align}
12c(k)^3 &= -c'(k) \cr
-12\,dk &= \frac{dc}{c^3}
\end{align}

Integrating both sides:

\begin{align}
\int -12\,dk &= \int c^{-3}\,dc \cr
-12k + A &= \frac{c^{-2}}{-2} \cr
c(k)^2 &= \frac{1}{24k - 2A} \cr
c(k) &= \frac{1}{\sqrt{24k + B}}
\end{align}

where $B=-2A$ is the constant of integration.

**Step 3: Applying the Boundary Condition.** To find the constant $B$, we must match our continuous solution to the known behavior of the first machine ($k=1$). The first machine's dynamics are described by the discrete ODE using our derived physics:

$$\frac{ds_1}{dt} = o_0 - o_1 \approx \frac{1}{2} - \left(\frac{1}{2} - \frac{1}{24s_1}\right) = \frac{1}{24s_1}$$

Solving this ODE for $s_1(t)$ with the initial condition $s_1(0)=0$:

\begin{align}
24s_1\,ds_1 &= dt \cr
\int_0^{s_1(t)} 24s_1'\,ds_1' &= \int_0^t d\tau \cr
12s_1(t)^2 &= t
\end{align}

This proves that $s_1(t) = \sqrt{t/12}$. Therefore, our coefficient function must satisfy $c(1) = 1/\sqrt{12}$:

\begin{align}
c(1) &= \frac{1}{\sqrt{12}} \cr
\left(\frac{1}{\sqrt{12}}\right)^2 &= \frac{1}{24(1)+B} \cr
\frac{1}{12} &= \frac{1}{24+B} \cr
B &= -12
\end{align}

**Step 4: Final Solution for Storage.** With the constant $B$ determined, we have the complete solution for the expected storage:

$$\boxed{s(k,t) = \sqrt{\frac{t}{24k-12}}}$$

---

### Conclusion

By substituting our solution for $s(k,t)$ back into the output law, we also find the solution for the expected output:

<p>
$$\boxed{o(k,t) = \frac{1}{2} - \frac{\sqrt{24k-12}}{24\sqrt{t}}}$$
</p>

This journey, from a complex stochastic process to a simple, elegant closed-form solution, showcases the power of theoretical modeling. By making a physically motivated mean-field assumption—that the complex distribution of storage could be approximated as exponential—we were able to derive a continuous model that accurately captures the long-term behavior of the entire system. 

The final equations reveal a clear picture: storage at each machine grows with the square root of time, while the output slowly approaches the steady-state value of $1/2$, with both dynamics governed by the machine's position in the pipeline. This elegant mathematical structure emerges from what initially appeared to be intractable stochastic chaos, demonstrating the profound insights that can be gained through careful theoretical analysis.

// Wait for Plotly to load
function waitForPlotly(callback) {
    if (typeof Plotly !== 'undefined') {
        callback();
    } else {
        setTimeout(() => waitForPlotly(callback), 100);
    }
}

waitForPlotly(() => {
    const colors = ['#ef4444', '#3b82f6', '#10b981', '#f59e0b', '#8b5cf6'];

    window.simulatePipeline = function(m, d, r) {
        const sSum = Array(m).fill(null).map(() => Array(d).fill(0));
        const oSum = Array(m).fill(null).map(() => Array(d).fill(0));
        
        for (let run = 0; run < r; run++) {
            const s = Array(m).fill(null).map(() => Array(d + 1).fill(0));
            const o = Array(m).fill(null).map(() => Array(d).fill(0));
            
            for (let day = 0; day < d; day++) {
                const cap = Array(m).fill(0).map(() => Math.random());
                for (let k = 0; k < m; k++) {
                    const avail = s[k][day] + (k === 0 ? 1.0 : o[k-1][day]);
                    o[k][day] = Math.min(cap[k], avail);
                    s[k][day + 1] = avail - o[k][day];
                }
            }
            
            for (let k = 0; k < m; k++) {
                for (let day = 0; day < d; day++) {
                    sSum[k][day] += s[k][day + 1];
                    oSum[k][day] += o[k][day];
                }
            }
        }
        
        return {
            storage: sSum.map(row => row.map(val => val / r)),
            output: oSum.map(row => row.map(val => val / r))
        };
    }

    function theoreticalPred(m, times) {
        const c = Array(m).fill(0);
        c[0] = 1 / Math.sqrt(12);
        
        for (let k = 1; k < m; k++) {
            const cp = c[k-1];
            c[k] = (Math.sqrt(1 + 48 * cp * cp) - 1) / (24 * cp);
        }
        
        const sT = Array(m).fill(null).map(() => Array(times.length).fill(0));
        const oT = Array(m).fill(null).map(() => Array(times.length).fill(0));
        
        for (let t = 0; t < times.length; t++) {
            sT[0][t] = 0.5 * times[t];
            oT[0][t] = 0.5;
            for (let k = 1; k < m; k++) {
                sT[k][t] = c[k] * Math.sqrt(times[t]);
                oT[k][t] = 0.5 - 1 / (24 * c[k] * Math.sqrt(times[t]));
            }
        }
        
        return { storage: sT, output: oT };
    }

    window.updatePlots = function() {
        const m = parseInt(document.getElementById('numMachines').value);
        const d = parseInt(document.getElementById('numDays').value);
        const r = parseInt(document.getElementById('numRuns').value);
        
        const sim = simulatePipeline(m, d, r);
        const times = Array.from({length: d}, (_, i) => i + 1);
        const theory = theoreticalPred(m, times);
        
        const sTraces = [];
        const oTraces = [];
        const maxM = Math.min(m, 6);
        
        for (let k = 1; k < maxM; k++) {
            const col = colors[k - 1];
            sTraces.push(
                {x: times, y: sim.storage[k], name: `M${k+1} (MC)`, line: {color: col, width: 2.5}},
                {x: times, y: theory.storage[k], name: `M${k+1} (th)`, line: {color: col, dash: 'dash'}}
            );
            
            const sDist = sim.output[k].map(v => Math.abs(0.5 - v));
            const tDist = theory.output[k].map(v => Math.abs(0.5 - v));
            oTraces.push(
                {x: times, y: sDist, name: `M${k+1}`, line: {color: col, width: 2.5}, showlegend: false},
                {x: times, y: tDist, line: {color: col, dash: 'dash'}, showlegend: false}
            );
        }
        
        const layout = {
            xaxis: {title: 'Time (days)'},
            yaxis: {title: 'Expected Storage'},
            title: 'Storage Evolution',
            margin: {t: 40, b: 40, l: 50, r: 20}
        };
        
        const layoutOut = {
            xaxis: {title: 'Time (days)', type: 'log'},
            yaxis: {title: 'Distance to Steady State', type: 'log'},
            title: 'Output Convergence',
            margin: {t: 40, b: 40, l: 60, r: 20}
        };
        
        Plotly.newPlot('storage-plot', sTraces, layout, {responsive: true, displayModeBar: false});
        Plotly.newPlot('output-plot', oTraces, layoutOut, {responsive: true, displayModeBar: false});
    }

    updatePlots();
});
</script>
